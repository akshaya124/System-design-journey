# Learning Resources

A curated starting list for learning system design. Prefer understanding and implementing concepts over collecting many courses.

## Fundamentals and HLD
- [System Design Primer](https://github.com/donnemartin/system-design-primer) — broad concepts, trade-offs, and interview preparation.
- [Free System Design](https://freesystemdesign.com/) — interactive lessons and visual explanations.
- [Gaurav Sen on YouTube](https://www.youtube.com/@gkcs) — system design and distributed systems explanations.
- [ByteByteGo on YouTube](https://www.youtube.com/@ByteByteGo) — visual system design explanations.

## SQL and databases
- [SQLBolt](https://sqlbolt.com/) — interactive SQL lessons.
- [PostgreSQL Documentation](https://www.postgresql.org/docs/) — official reference.
- [MongoDB University](https://learn.mongodb.com/) — learning resources for MongoDB.

## LLD and design patterns
- [Refactoring.Guru — Design Patterns](https://refactoring.guru/design-patterns) — pattern explanations and examples.
- [Awesome Low-Level Design](https://github.com/ashishps1/awesome-low-level-design) — LLD study material and practice ideas.

## API practice
- [JSONPlaceholder](https://jsonplaceholder.typicode.com/) — fake REST API for practice.
- [Postman Learning Center](https://learning.postman.com/) — learn to send requests and inspect responses.

## Suggested study method
1. Read one lesson.
2. Draw the idea from memory.
3. Explain it out loud in simple words.
4. Complete the practice task.
5. Revisit the notes before interviews and update them when understanding improves.
