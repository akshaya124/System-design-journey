# System Design Journey

A day-by-day learning repository documenting my journey from system design fundamentals to Low-Level Design (LLD), High-Level Design (HLD), and practical architecture exercises.

## Learning goals

- Understand how clients, servers, APIs, and databases work together.
- Learn HTTP, REST, SQL/NoSQL, data modeling, and indexing.
- Study scalability, caching, load balancing, and reliability.
- Practice OOP, SOLID principles, design patterns, and LLD in Java.
- Design systems through requirements, diagrams, trade-offs, and case studies.
